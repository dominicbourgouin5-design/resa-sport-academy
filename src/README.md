# RESA Sport Academy — Maquette fonctionnelle

Site officiel de RESA Sport Academy et plateforme de la Ligue Scolaire Primaire de Côte d'Ivoire.

## Stack

- **Next.js 15** (App Router, React 19)
- **TypeScript**
- **Tailwind CSS v4**
- **next-intl** (bilingue FR / EN)
- **Supabase** (PostgreSQL, Auth, Storage, RLS)
- **Tiptap** (éditeur riche pour les actualités)
- Hébergement : **Vercel**

## Environnement local

```bash
npm install
cp .env.example .env.local  # si présent
npm run dev
